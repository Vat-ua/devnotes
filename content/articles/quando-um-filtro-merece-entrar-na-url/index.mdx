Um filtro merece entrar na URL quando descreve a página que alguém está vendo. Se recarregar, copiar o link ou usar Voltar deve restaurar o mesmo catálogo, a busca, a categoria e a ordenação são parte do endereço — não apenas do componente.

No Lab Catálogo de ferramentas, esses valores vêm de `useSearchParams()`:

```jsx
const [searchParams, setSearchParams] = useSearchParams();
const query = searchParams.get('q') ?? '';
const category = searchParams.get('category') ?? 'Todos';
const sortBy = searchParams.get('sort') ?? 'name';
```

Com isso, `/labs/catalogo-de-ferramentas?category=Frontend&sort=popularity` já é uma descrição completa daquela visualização.

## Atualize um parâmetro sem apagar os outros

Ao trocar a categoria, a busca e a ordenação atuais precisam continuar na URL. Comece a alteração a partir dos parâmetros existentes, não de uma query string nova.

```js
function updateParam(name, value) {
  setSearchParams(
    (currentParams) => {
      const nextParams = new URLSearchParams(currentParams);
      const isDefault =
        (name === 'category' && value === 'Todos') || (name === 'sort' && value === 'name');

      if (!value || isDefault) {
        nextParams.delete(name);
      } else {
        nextParams.set(name, value);
      }

      return nextParams;
    },
    { replace: true },
  );
}
```

No Lab, os valores padrão também são removidos: `category=Todos` e `sort=name` não acrescentam informação. O `{ replace: true }` evita criar uma entrada no histórico a cada letra digitada; use a navegação normal quando cada mudança precisar virar uma etapa do histórico.

## Leia a URL; derive a lista

A URL guarda a intenção, não uma cópia dos resultados. A lista visível continua sendo calculada a partir dos parâmetros e dos dados de origem:

```jsx
const visibleTools = tools
  .filter((tool) => matchesQuery(tool, query.trim().toLowerCase()))
  .filter((tool) => matchesCategory(tool, category))
  .toSorted((first, second) => sortTools(first, second, sortBy));
```

Isso evita ter uma lista em `useState` que precisa ser sincronizada com filtros, ordenação e URL.

## Quando deixá-la de fora

Não coloque na query string um tooltip aberto, o foco do teclado, uma mensagem temporária de cópia ou o texto de um formulário que ainda não foi aplicado. Esses estados não descrevem uma página que vale a pena compartilhar ou restaurar.

Use a URL para a visão do conteúdo; mantenha local o que só existe durante a interação atual.
