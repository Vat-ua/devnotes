Buscar dados parece simples até o primeiro atraso de rede, a primeira resposta vazia ou a primeira troca rápida de tela. É nesses momentos que a interface precisa ter uma opinião.

## Quatro estados são suficientes para começar

Comece descrevendo inicial, carregando, pronto e erro. Cada um merece uma saída visível, mesmo que curta. Essa decisão organiza o componente antes de qualquer biblioteca entrar na conversa.

```jsx
if (status === "loading") return <LoadingState />;
if (status === "error") return <ErrorState />;

return <ResourceList items={data} />;
```

A arquitetura pequena funciona porque deixa as fronteiras explícitas: a função que busca, a transformação dos dados e a interface que os apresenta.
