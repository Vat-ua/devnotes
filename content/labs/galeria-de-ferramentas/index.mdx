## Os dados vêm primeiro

`tools` é um array de objetos. Cada objeto descreve uma ferramenta e reúne informações como `id`, nome, categoria, descrição, tags, casos de uso e, quando necessário, a indicação de destaque. Esses dados ficam separados dos componentes. Assim, podemos mudar o conteúdo da galeria sem repetir a estrutura dos cards.

## Um objeto vira um componente

`ToolGallery` percorre o array com `.map()` e cria um `ToolCard` para cada ferramenta:

```jsx
<ToolGrid>
  {tools.map((tool) => (
    <ToolCard
      key={tool.id}
      name={tool.name}
      category={tool.category}
      description={tool.description}
      tags={tool.tags}
      useCases={tool.useCases}
      featured={tool.featured}
    />
  ))}
</ToolGrid>
```

A estrutura de `ToolCard` continua a mesma, mas as props recebem valores diferentes a cada item do array. É isso que permite reutilizar o mesmo componente para mostrar ferramentas diferentes. Em `ToolCard`, `featured = false` também define um valor padrão para os casos em que essa prop não é informada.

## `key` identifica cada item da lista

`key={tool.id}` ajuda o React a identificar cada card entre uma renderização e outra. Como o `id` vem dos próprios dados, ele é uma boa escolha: é único para cada ferramenta e permanece estável. A `key` é usada pelo React e não chega a `ToolCard` como uma prop comum.

## Composição divide responsabilidades

A galeria também é formada por componentes menores. `ToolGrid` recebe os cards por `children` e cuida do layout. `ToolDetails` cuida da parte expansível de cada card e é usado dentro de `ToolCard`. Assim, cada componente fica responsável por uma parte específica da interface, e juntos eles formam a galeria completa.
