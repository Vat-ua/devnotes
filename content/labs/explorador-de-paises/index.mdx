## Como o exemplo foi construído

Os países vêm de um arquivo de dados local. O componente principal não mantém uma segunda lista no estado: guarda apenas a busca, o continente e a ordenação escolhida.

A partir desses três valores, a lista visível é derivada com filter() e toSorted(). Isso evita duplicar dados no estado e mantém o resultado previsível.

## O que vale reaproveitar

- Use uma chave estável e única para cada card, como um `id`.
- Mantenha os inputs como componentes controlados.
- Use `<details>` e `<summary>` quando um accordion simples for suficiente.
- Trate a lista vazia como um estado legítimo da interface.
