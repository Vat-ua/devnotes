## A fronteira da API

`fetchCharacters()` concentra a URL, os parâmetros, o tratamento de erros HTTP e a adaptação da resposta. O restante da interface não precisa conhecer o formato bruto da API nem montar URLs manualmente.

A função `toCharacter()` seleciona apenas os campos que a interface realmente usa. Essa tradução cria um modelo pequeno, estável e fácil de renderizar nos cards.

## O que vale reaproveitar

- Cancele requisições que deixam de representar a busca atual com `AbortController`.
- Trate um `404` como lista vazia quando essa for a convenção da API para buscas sem resultados.
- Mantenha carregamento, vazio e erro como estados distintos da interface.
- Use a próxima página informada pela API, em vez de tentar deduzir quando a lista terminou.
