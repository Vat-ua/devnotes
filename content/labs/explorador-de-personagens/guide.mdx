## A fronteira da API

`fetchCharacters()` concentra a URL, os parâmetros, os erros HTTP e a adaptação da resposta. O restante da interface não precisa conhecer o formato bruto da API nem montar URLs manualmente.

A função `toCharacter()` escolhe os campos que o produto realmente usa. Essa tradução cria um modelo pequeno, estável e fácil de renderizar nos cards.

## O que vale reaproveitar

- cancele requests que deixam de representar a busca atual com `AbortController`;
- trate `404` de uma busca como lista vazia quando essa for a convenção da API;
- mantenha loading, vazio e erro como estados distintos da interface;
- preserve a próxima página retornada pela API, em vez de adivinhar quando a lista terminou.
