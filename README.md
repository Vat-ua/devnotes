# DevNotes

DevNotes é um site editorial sobre desenvolvimento web, com artigos curtos e Labs interativos para explorar ideias diretamente no navegador.

O projeto foi criado durante o curso Full Stack da Toti. Ele reúne exercícios, decisões de implementação e pequenos experimentos que podem ser úteis para quem está começando a estudar desenvolvimento web — sem a pretensão de ser um guia definitivo.

Os Articles apresentam contexto e escolhas técnicas; os Labs transformam parte dessas ideias em interfaces que podem ser testadas no navegador e exploradas diretamente no código.
